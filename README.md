# Sangna Acharya BM — Personal Developer Portfolio

Welcome to the official GitHub repository for my personal developer portfolio, built for FOLIOFORGE 2026 (organized by ComputeX | Math & Computing Club, M.S. Ramaiah University of Applied Sciences).

---

## Live Demo & Links
- **Live Website:** [Deployed on Vercel](https://portfolio-folioforge.vercel.app)
- **GitHub Repository:** [github.com/sangna3087/portfolio-folioforge](https://github.com/sangna3087/portfolio-folioforge)

---

## Features & Design Concept
- **Aesthetic Theme:** Crafted with a sleek professional black background combined with clean purplish accents (deep violet gradients, soft lavender highlights, glowing purple borders, and modern glassmorphism containers).
- **Interactive UI:** Fully responsive layout optimized across mobile devices, tablets, and desktops using Tailwind CSS grids and flexbox.
- **Personal Touch:** Includes a clean custom avatar frame, structured sections, and smooth hover transitions.

---

## Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Version Control:** Git & GitHub (`sangna3087`)
- **Deployment:** Vercel
